Biodefense / MCM cardiac safety · CiPA-aligned MEA scoring

Browser implementation of the CardioScore engine for medical countermeasure (MCM) and biodefense-oriented screening: vaccines, antitoxins, antivirals, and related candidates. Generate synthetic multi-well MEA feature tables, tune endpoint weights, optionally upload a CSV of pre-extracted features, score to Low / Moderate / High, and export JSON or CSV. Full Python pipeline is on GitHub. Research framework only — not a regulatory assay.
